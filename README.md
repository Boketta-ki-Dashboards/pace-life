## Isolation und Datenschutz
Pace Social wird **ausschließlich von Claude** betreut. Kein Codex-Zugriff auf dessen Repository. Keine produktiven Supabase-Änderungen oder eigenmächtige Account-Verknüpfung.

Das Repository ist momentan **öffentlich**. Nutzerseitige Bildschirmaufnahmen und daraus extrahierte Einzelbilder mit potenziellen Nutzernamen/Chats sind daher bewusst **nicht** enthalten. Design-Tokens und Gestaltungsregeln sind textlich festgehalten. Nach Datenschutzprüfung können bereinigte Referenzbilder separat hinzugefügt werden.
